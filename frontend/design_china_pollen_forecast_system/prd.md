# 中国全域花粉预报系统 产品需求文档 (PRD)

## 1. 文档概览
- **产品名称**：中国全域花粉预报系统 (China Pollen Forecast System)
- **目标用户**：气象业务人员、环境监测专家、科研人员、系统管理员
- **核心价值**：通过自动化运行 WRF-Pollen 模式，实现中国全域高精度的花粉浓度预报，并提供专业的可视化展示与业务流程管理。

---

## 2. 业务背景与目标
### 2.1 业务背景
目前花粉预报多依赖手动运行模式或零散的脚本，缺乏统一的业务化管理平台。本系统旨在解决预报流程复杂、Slurm 调度繁琐、结果展示不直观等痛点。
### 2.2 核心目标
1. **自动化预报**：实现从数据前处理（WPS）到模式运行（WRF）再到后处理（成图）的全流程自动化。
2. **专业可视化**：提供 NASA 风格的 WebGIS 地图，支持多层级、多时次、多品种的花粉预报展示。
3. **流程可编排**：借鉴 ecFlow 逻辑，支持可视化流程编排与模板复用。

## 3. 功能需求

### 3.1 首页 (预报展示门户) - {{DATA:SCREEN:SCREEN_8}}
- **WebGIS 主地图**：
  - 支持中国全域渲染，支持平移缩放。
  - **图层控制**：支持切换浓度、健康风险等级等图层。
  - **区域切换**：支持 d01 (低分辨率/广域) 与 d02 (高分辨率/精细化) 切换。
  - **时间轴**：播放/暂停未来 24h/72h 的预报演变。
- **分析卡片**：
  - 自动生成重点城市的时间序列折线图、区域对比柱状图等。
- **入口**：右上角“控制台”按钮触发管理员登录。

### 3.2 管理员登录 - {{DATA:SCREEN:SCREEN_2}}
- **安全验证**：仅需输入管理员访问密码即可进入后台系统。
- **设计风格**：极简弹窗，强调业务系统的封闭性。

### 3.3 预报管理中心 (后台概览) - {{DATA:SCREEN:SCREEN_6}}
- **运行监控**：实时显示活跃调度器数量、Slurm 作业队列状态、系统健康度。
- **模块导航**：快速跳转至任务调度、流程配置、产品管理、系统日志等模块。
- **实时日志**：展示系统级别的运行流水。

### 3.4 流程编排与工作流配置 - {{DATA:SCREEN:SCREEN_7}}
- **模板管理**：预设“全国日常预报”、“d02精细化预报”等模板。
- **DAG 可视化**：
  - 节点包括：geogrid, ungrib, metgrid, WPS, 花粉预插值, WRF预报, WRF后处理, 成图发布。
  - 节点状态：通过颜色区分（绿色-成功，蓝色-运行中，红色-失败）。
- **参数配置**：针对 Slurm 环境配置 CPU 核数、内存、Walltime、计算队列等。
- **执行控制**：支持整链运行、单点重跑、失败节点断点续跑。

### 3.5 定时任务管理 - {{DATA:SCREEN:SCREEN_5}}
- **调度配置**：支持设置每日定时执行（如 04:00 UTC），关联特定的流程模板。
- **执行流水**：记录每次定时任务的成功率、耗时及 Slurm Job ID。

### 3.6 预报结果与产品管理 - {{DATA:SCREEN:SCREEN_4}}
- **产品档案**：集中管理生成的成图（PNG/PDF）、地理数据（GeoJSON/GeoTIFF）。
- **操作**：支持批量导出、重新生成、发布状态切换。

## 4. 非功能需求

### 4.1 视觉与交互
- **风格**：NASA 气象业务系统感，深色主题 (#121414)，科技蓝/青色高亮。
- **适配**：优先适配桌面端大屏浏览器 (1920x1080 及以上)。

### 4.2 技术栈 (推荐)
- **前端**：React + TypeScript + Ant Design + OpenLayers (GIS)。
- **后端**：Python (FastAPI) - 适合与科研脚本/Slurm 命令行工具集成。
- **调度引擎**：封装 Slurm 命令行工具 (`sbatch`, `squeue`)。
- **部署环境**：RedHat 7.4 / CentOS 7。

---

## 5. 术语表
- **WRF-Pollen**：基于 WRF-Chem 修改的花粉传播模式。
- **d01/d02**：WRF 模式中的嵌套层级，d01 为外层大区域，d02 为内层加密区。
- **Slurm**：一种广泛用于高性能计算集群的开源作业调度系统。
- **DAG**：有向无环图，用于表示任务之间的逻辑依赖关系。
